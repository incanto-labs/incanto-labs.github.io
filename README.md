# incanto-labs.github.io

The Incanto Labs website, served by GitHub Pages at <https://incanto-labs.github.io>.
It is the **Website** on the Wota Ringu Toss Play listing.

| Path | What it is |
|---|---|
| `app-ads.txt` | AdMob's authorized-seller line. It must stay at the site root, or AdMob stops verifying the app. |
| `index.html` | The home page. |
| `wota-ringu-toss/privacy/` | The Wota Ringu Toss privacy policy. Its text is `docs/privacy-policy.md` in the game repo: change both together. |
| `assets/` | The stylesheet, the game icon, and Nunito (SIL Open Font License, `assets/fonts/OFL.txt`), subset to Latin. |

The pages load nothing from other sites: no fonts, scripts or trackers.
